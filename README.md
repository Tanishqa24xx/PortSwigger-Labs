# PortSwigger Web Security Academy - Write-ups

A collection of my write-ups from the PortSwigger Web Security Academy, documenting hands-on exploitation of web application vulnerabilities across various topics.

## About This Repository

Each file in this repo corresponds to a single vulnerability topic (e.g., SQL Injection) and consolidates every related lab under that topic into one write-up. Rather than listing topics/labs here — since that list grows over time — write-ups are organized by file, browsable directly in the repo structure.

## Structure

Each write-up generally includes:

- **Relevant theory and payload references** for the vulnerability class.
- **Lab-by-lab walkthroughs** — the exact approach taken, payloads used, dead ends hit, and the final working exploit.
- **Tools used** — primarily Burp Suite (Repeater, Intruder, Collaborator) alongside browser dev tools.

This reflects a practical, trial-and-error methodology: understanding the vulnerability class, probing the application, adapting when blocked, and confirming exploitation.

## What This Demonstrates

- **Deep, hands-on understanding** of web vulnerability classes — not just theory, but working exploitation across varying difficulty levels and edge cases (filter bypasses, blind/out-of-band techniques, DB-specific syntax differences).
- **Persistence and adaptability** — documented attempts include failed payloads and pivots, not just clean solutions.
- **Tool proficiency** — Burp Suite Repeater, Intruder, and Collaborator used extensively for manual and semi-automated exploitation.
- **Clear technical documentation** — each step recorded for reproducibility and review.

## Disclaimer

All content in this repository was obtained through legal, authorized lab environments (PortSwigger Web Security Academy) intended for educational purposes. None of the techniques, credentials, or findings documented here apply to real, production, or third-party systems.
